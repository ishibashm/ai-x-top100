# Android コントロールアプリ - セットアップガイド

For You / JEV Voiceスタック用のAndroidリモートコントロールアプリの詳細ガイドです。

## 📱 概要

このアプリケーションは、スマートフォン（Android）からPC上で動作するFor You/JEV Voiceサーバーをリモート操作するためのプログレッシブウェブアプリ（PWA）です。

### アーキテクチャ

```
┌─────────────┐         LAN WiFi         ┌──────────────┐
│   Android   │ ◄─────WebSocket/HTTP────► │  PC Server   │
│     PWA     │      (認証トークン)       │   Node.js    │
└─────────────┘                           └──────────────┘
                                                  │
                                                  ├── TYPESAFE_API_KEY
                                                  ├── foryou-data.json
                                                  └── Chrome拡張連携
```

### 重要な設計原則

- ✅ **TYPESAFE_API_KEY**: PC側のみで保持、APKには含まれません
- ✅ **認証トークン**: サーバー起動時に生成され、LAN接続時に必要
- ✅ **LAN限定**: 同一Wi-Fiネットワーク内での使用を想定
- ✅ **サーバー依存**: スマートフォンが直接Chromeを操作することはありません

## 🚀 セットアップ手順

### ステップ1: PC側サーバーのセットアップ

#### 1.1 依存関係のインストール

```bash
cd apps/jev-voice-server
npm install
```

#### 1.2 環境変数の設定（オプション）

`.env` ファイルを作成（任意）:

```bash
# サーバーポート
PORT=8765

# ホスト設定（LAN接続を許可）
HOST=0.0.0.0

# 固定トークン（省略時は自動生成）
AUTH_TOKEN=your-secure-token-here

# Typesafe APIキー（必要に応じて）
TYPESAFE_API_KEY=your-api-key-here
```

#### 1.3 サーバー起動

```bash
npm start
```

起動成功時、以下のような情報が表示されます：

```

  JEV Voice Server Started
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

```

**重要**: 表示された **Auth Token** を控えてください。これがスマートフォンからの接続に必要です。

### ステップ2: PCのIPアドレス確認

スマートフォンからPC上のサーバーに接続するために、PCのローカルIPアドレスを確認します。

#### Windows

コマンドプロンプトで:
```cmd
ipconfig
```

`IPv4 アドレス` の行を確認（例: `192.168.1.100`）

#### macOS

ターミナルで:
```bash
ifconfig | grep "inet "
```

または、システム環境設定 → ネットワーク → Wi-Fi → 詳細

#### Linux

ターミナルで:
```bash
ip addr show
```

または:
```bash
hostname -I
```

### ステップ3: Wi-Fi設定の確認

**PCとスマートフォンが同じWi-Fiネットワークに接続されている必要があります。**

#### チェック項目

1. PCとスマートフォンが同じSSIDに接続されているか
2. ゲストネットワークではないか（デバイス間通信が制限される場合があります）
3. VPNが有効になっていないか

### ステップ4: ファイアウォール設定

PCのファイアウォールでポート8765への接続を許可します。

#### Windows Defender Firewall

管理者権限でPowerShellを開き:

```powershell
New-NetFirewallRule -DisplayName "JEV Voice Server" -Direction Inbound -Protocol TCP -LocalPort 8765 -Action Allow
```

または、Windows Defenderファイアウォール → 詳細設定 → 受信の規則 → 新しい規則

#### macOS

システム環境設定 → セキュリティとプライバシー → ファイアウォール → ファイアウォールオプション

Node.jsの接続を許可してください。

#### Linux (UFW)

```bash
sudo ufw allow 8765/tcp
```

### ステップ5: Androidアプリのセットアップ

#### 方法A: PWA（推奨、最も簡単）

1. スマートフォンのChromeブラウザで、以下のいずれかの方法でアプリにアクセス:
   
   **オプション1: GitHub Pages（公開されている場合）**
   ```
   https://ishibashm.github.io/ai-x-top100/apps/android-control/public/
   ```
   
   **オプション2: ローカルHTTPサーバー経由**
   ```bash
   cd apps/android-control/public
   python3 -m http.server 8080
   ```
   
   スマートフォンのブラウザで `http://[PC_IP]:8080` にアクセス

2. ブラウザのメニュー（⋮）から **「ホーム画面に追加」** を選択

3. アプリ名を確認して **「追加」** をタップ

4. ホーム画面にアイコンが追加されます

#### 方法B: Capacitor（ネイティブ機能が必要な場合）

より深いネイティブ統合が必要な場合:

```bash
cd apps/android-control

# Capacitorのセットアップ
npm install @capacitor/core @capacitor/cli
npx cap init "For You Control" "com.foryou.control"
npx cap add android

# ビルドと同期
npm run build  # 必要に応じて
npx cap sync
npx cap open android
```

Android Studioでビルドしてインストールします。

### ステップ6: アプリの初回接続

1. ホーム画面からアプリを起動

2. **サーバーURL** に以下の形式で入力:
   ```
   ws://[PCのIPアドレス]:8765
   ```
   例: `ws://192.168.1.100:8765`

3. **認証トークン** にステップ1で控えたトークンを入力

4. **「接続」** ボタンをタップ

5. 接続成功時、ステータスが **「接続完了」** に変わり、コマンドセクションが表示されます

## 🔒 セキュリティ

### 認証トークンの管理

- トークンはサーバー起動時に自動生成されます
- 環境変数 `AUTH_TOKEN` で固定トークンを設定可能
- トークンはアプリのlocalStorageに保存されます
- トークンを他人と共有しないでください

### TYPESAFE_API_KEYの保護

- `TYPESAFE_API_KEY` は **PCサーバー側のみ** に保存されます
- Androidアプリには含まれません
- APKファイルに含まれることはありません
- 環境変数またはサーバーの設定ファイルで管理してください

### ネットワークセキュリティ

- LAN内通信のみを想定しています
- インターネット経由でのアクセスは推奨しません
- 必要に応じてVPNを使用してください

## 🔧 トラブルシューティング

### 接続できない

#### 症状: 「接続エラー」または「タイムアウト」

**解決方法:**

1. **同じWi-Fiに接続しているか確認**
   - PCとスマートフォンのWi-Fi設定を確認
   - SSIDが同じか確認

2. **IPアドレスが正しいか確認**
   - PCのIPアドレスを再確認
   - `127.0.0.1` や `localhost` は使用できません

3. **サーバーが起動しているか確認**
   - PCでサーバーのコンソールを確認
   - `npm start` でサーバーを起動

4. **ファイアウォールを確認**
   - ポート8765が許可されているか確認
   - 一時的にファイアウォールを無効化してテスト

5. **ポート番号を確認**
   - デフォルトは8765
   - サーバー起動時の表示と一致しているか確認

### 認証エラー

#### 症状: 「Unauthorized」または「401エラー」

**解決方法:**

1. **トークンが正しいか確認**
   - サーバーコンソールに表示されたトークンと一致しているか
   - コピー&ペーストで入力

2. **トークンに余分な空白がないか確認**

3. **サーバーを再起動**
   - 新しいトークンが生成されます
   - 新しいトークンで再接続

### データが表示されない

#### 症状: 「アカウント数: -」

**解決方法:**

1. **foryou-data.jsonが存在するか確認**
   - サーバーのルートディレクトリに配置
   - `apps/jev-voice-server/../../foryou-data.json`

2. **JSONファイルが正しいフォーマットか確認**
   ```bash
   node scripts/build-foryou.mjs --check
   ```

### PWAがインストールできない

#### 症状: 「ホーム画面に追加」が表示されない

**解決方法:**

1. **HTTPSまたはlocalhostで提供されているか確認**
   - PWAはセキュアな環境が必要
   - ローカルHTTPサーバーの場合は `localhost` を使用

2. **manifest.jsonが読み込まれているか確認**
   - ブラウザの開発者ツール → Application → Manifest

3. **ChromeまたはEdgeを使用**
   - 他のブラウザではPWAのサポートが限定的な場合があります

## 🚫 制限事項

### できないこと

1. **スマートフォンからデスクトップChromeを直接操作**
   - アーキテクチャ上、PC上のサーバーが必要です
   - サーバーがChromeとの橋渡しを行います

2. **インターネット経由での操作**
   - 同一LAN内での使用を前提としています
   - 外部からのアクセスには別途VPNなどが必要

3. **音声認識**
   - 現在は準備中です
   - テキストコマンドのみ使用可能

4. **Play Storeでの配布**
   - PWAとして提供されます
   - ネイティブアプリの公開は行いません
