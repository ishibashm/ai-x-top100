# 音声→Jev→MCPアーキテクチャ / Voice→Jev→MCP Architecture

このドキュメントでは、音声入力からMCPボードへのデータフローと、各コンポーネントの役割について説明します。

## 各層の詳細

### 1. 音声認識層

- **技術:** Web Speech API（Chrome/Edgeのみ）
- **機能:**
  - リアルタイムで音声をテキストに変換
  - 部分的なトランスクリプト（interim results）を送信
  - 最終結果の確定
- **制限:**
  - Firefox/Safariは非対応
  - 音声データはGoogleに送信される

### 2. Jevクエリ層

- **技術:** TypeSafe Jev Model (`jev-1.13.0`)
- **特徴:**
  - テキスト生成なし（選択のみ）
  - 型付き質問（Choice/Noul/Score）
  - 並列質問処理
  - 高速レスポンス（250-350ms）
- **質問タイプ:**
  - **Choice:** 複数の選択肢から1つ選択（例：intent, target, site）
  - **Noul:** Yes/No質問（例：is_command, complete, destructive）
  - **Score:** スコアリング質問（例：scroll_amount）

### 3. ポリシー判定層

決定木に基づく閾値判定：

```
is_command ≥ 0.5?
├─ No → 無視
└─ Yes → intent.confidence ≥ 0.55?
          ├─ No → 待機
          └─ Yes → complete ≥ 0.6 or 沈黙?
                   ├─ No → 待機
                   └─ Yes → destructive ≥ 0.5?
                            ├─ Yes → 確認要求
                            └─ No → 実行
```

### 4. ブラウザ制御層

- **技術:** Playwright + Chromium
- **特徴:**
  - ヘッドありウィンドウ（デフォルト）
  - 永続プロファイル（ログイン状態保持）
  - CDP接続オプション
- **操作:**
  - ナビゲーション（go to, back, forward）
  - クリック（要素選択）
  - 入力（type, select）
  - スクロール（down, up, page, bottom）

### 5. For You統合層

収集したコンテンツをFor Youボードに統合するための変換処理：

```javascript
// 音声ブラウザで収集したデータ
{
  url: "https://example.com/article",
  title: "Breaking AI News",
  summary: "New model achieves SOTA..."
}

// ↓ 変換

// For You形式
{
  id: "voice_001",
  author: "Voice Collected",
  handle: "voicecollected",
  text: "Breaking AI News: New model achieves SOTA...",
  url: "https://example.com/article",
  createdAt: "2026-09-20T04:00:00Z"
}
```

## データフローの例

### ケース1: ニュース検索と収集

```
1. ユーザー: "search for AI news on Hacker News"
2. Web Speech API → トランスクリプト配信
3. jev-voice-browser → 200ms デバウンス
4. スナップショット → ページ要素収集
5. Jev → 意図分類
   - intent: search_web
   - site: hacker_news
   - complete: 0.95
   - is_command: 0.98
6. ポリシー → 実行判定
7. Playwright → Hacker Newsで検索
8. コンテンツ抽出 → 記事リスト取得
9. voice-to-foryou-bridge → For You形式に変換
10. foryou-data.json → データ追加
11. build-foryou.mjs → HTML再生成
12. foryou.html → ユーザーに表示
```

### ケース2: 破壊的操作の確認

```
1. ユーザー: "click the delete button"
2. Jev → destructive: 0.85
3. ポリシー → 確認要求
4. トースト表示 → "Say 'confirm' or 'cancel'"
5. ユーザー: "confirm"
6. Playwright → ボタンクリック実行
```

## パフォーマンス特性

- **音声→決定:** 約300ms（200ms デバウンス含む）
- **Jevレスポンス:** 250-350ms（初回は約700ms）
- **入力トークン:** 3,000-6,000トークン/リクエスト
- **コスト:** $0.0002/リクエスト
- **30分セッション:** $0.01-0.05

## セキュリティ考慮事項

### APIキー管理

- `.env`ファイルで管理（`.gitignore`に含む）
- 環境変数からのみ読み取り
- ブラウザには送信しない
- Node.jsサーバー内でのみ使用

### ネットワーク

- デフォルト: `127.0.0.1`のみリッスン
- LAN使用: `--host 0.0.0.0`（信頼できるネットワークのみ）
- 制御ポートへのアクセス = ブラウザ制御 + API利用

### ブラウザプロファイル

- 永続プロファイル: `.browser-profile/`（gitignored）
- 重要なアカウントでのログイン非推奨
- 破壊的操作の確認プロンプトは補助的（保証ではない）

## 拡張性

### 新しいサイトの追加

`src/constants.js`の`SITES`に追加：

```javascript
{
  id: 'new_site',
  what: 'NewSite.com',
  examples: ['search NewSite for X', 'go to NewSite']
}
```

### 新しい意図の追加

`src/constants.js`の`INTENTS`に追加：

```javascript
{
  id: 'new_intent',
  what: 'describe the action',
  not_for: ['cases where it should not apply'],
  examples: ['example command 1', 'example command 2']
}
```

### For You形式のカスタマイズ

`scripts/voice-to-foryou-bridge.js`の変換ロジックを調整：

```javascript
function convertToForyouFormat(rawData) {
  return {
    id: generateId(),
    author: extractAuthor(rawData),
    handle: extractHandle(rawData),
    text: rawData.summary,
    textJa: translateToJapanese(rawData.summary),
    url: rawData.url,
    createdAt: new Date().toISOString()
  };
}
```

### よくある問題

1. **音声認識が動作しない**
   - Chrome/Edgeを使用
   - マイク権限を確認
   - HTTPSまたはlocalhostでアクセス

2. **Jevレスポンスが遅い**
   - 初回リクエストは約700ms（TLSハンドシェイク）
   - 2回目以降は250-350ms
   - ネットワーク接続を確認

3. **要素が見つからない**
   - スナップショットは最大100要素
   - スクロールして表示後に再試行
   - iFrame内の要素は非対応
