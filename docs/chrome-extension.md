# Chrome拡張機能のインストール手順

このドキュメントでは、Jev Voice Browser拡張機能をChromeに「パッケージ化されていない拡張機能」として読み込む方法を説明します。

## 前提条件

- Google Chrome（最新版推奨）
- Node.js（v18以上）
- このリポジトリのクローン

## ステップ1: サーバーのセットアップ

まず、バックエンドサーバーをセットアップします。

### 1.1 依存関係のインストール

```bash
cd third_party/jev-voice-browser
npm install
```

### 1.2 環境変数の設定

`.env`ファイルを作成します：

```bash
cp .env.example .env
```

`.env`ファイルを編集して、TypeSafe APIキーを設定します：

```env
TYPESAFE_API_KEY=your_actual_api_key_here
PORT=3456
```

**重要**: このAPIキーは拡張機能には含まれず、サーバー側でのみ管理されます。

### 1.3 サーバーの起動

```bash
npm start
```

または、開発モード（ファイル監視付き）：

```bash
npm run dev
```

サーバーが正常に起動すると、以下のように表示されます：

```
Jev Voice Browser server running on http://localhost:3456
WebSocket server ready on ws://localhost:3456
API Key configured: true
```

### 1.4 動作確認

ブラウザで以下のURLにアクセスして、サーバーが動作していることを確認します：

```
http://localhost:3456/health
```

以下のようなJSONレスポンスが返ってくれば正常です：

```json
{
  "status": "ok",
  "timestamp": "2026-09-20T05:00:00.000Z",
  "hasApiKey": true
}
```

## ステップ2: Chrome拡張機能の読み込み

### 2.1 Chrome拡張機能の管理画面を開く

以下のいずれかの方法で拡張機能の管理画面を開きます：

**方法1**: URLバーに直接入力
```
chrome://extensions/
```

**方法2**: メニューから
1. Chromeのメニュー（右上の三点アイコン）をクリック
2. 「その他のツール」→「拡張機能」を選択

### 2.2 開発者モードを有効にする

拡張機能の管理画面の右上にある「**開発者モード**」のトグルをオンにします。

![開発者モード](https://via.placeholder.com/400x100/7dd3a8/ffffff?text=%E9%96%8B%E7%99%BA%E8%80%85%E3%83%A2%E3%83%BC%E3%83%89%E3%82%92%E3%82%AA%E3%83%B3)

### 2.3 拡張機能を読み込む

1. 「**パッケージ化されていない拡張機能を読み込む**」ボタンをクリック

2. ファイル選択ダイアログが開くので、このリポジトリの `extensions/jev-voice/` ディレクトリを選択

   ```
   /path/to/repository/extensions/jev-voice/
   ```

3. 「**選択**」または「**フォルダを選択**」をクリック

### 2.4 拡張機能の確認

読み込みが成功すると、拡張機能のリストに「**Jev Voice Browser**」が表示されます。

以下の情報が表示されていることを確認します：

- **名前**: Jev Voice Browser
- **バージョン**: 1.0.0
- **ID**: （自動生成されたID）
- **説明**: 音声とテキストでブラウザを操作する拡張機能

## ステップ3: 拡張機能の使用

### 3.1 拡張機能を開く

Chromeのツールバーに追加された拡張機能アイコンをクリックします。

> **注**: アイコンが表示されていない場合は、ツールバーの拡張機能アイコン（パズルピース）をクリックして、「Jev Voice Browser」を探してください。

### 3.2 サイドパネルの確認

サイドパネルが開き、以下の画面が表示されます：

- **ヘッダー**: 🎤 Jev Voice
- **接続状態**: 「接続済み」（緑色の点）
- **音声入力ボタン**: 大きな円形ボタン
- **テキスト入力エリア**: 指示を入力するテキストボックス

接続状態が「**接続済み**」と表示されていれば、サーバーとの接続が確立されています。

### 3.3 音声入力を使う

1. **音声入力ボタン**（マイクアイコン）をクリック
2. 初回はマイクへのアクセス許可を求められるので、「**許可**」をクリック
3. ボタンが赤色になり、「録音中...」と表示されます
4. 音声で指示を話します（例：「Googleで検索」）
5. もう一度ボタンをクリックして録音を停止
6. 音声が認識され、結果が「応答」セクションに表示されます

### 3.4 テキスト入力を使う

1. テキスト入力エリアに指示を入力します
2. 「**送信**」ボタンをクリック、または `Ctrl+Enter`（Mac: `Cmd+Enter`）
3. 入力が処理され、結果が「応答」セクションに表示されます

### 3.5 設定

- **自動実行**: チェックを入れると、認識された指示を自動的に実行します
- **ログ**: 「ログ」セクションを開くと、詳細な動作ログを確認できます

## トラブルシューティング

### 問題1: 「接続中...」のまま接続できない

**原因**: サーバーが起動していない、またはポートが異なる

**解決方法**:
1. サーバーが起動しているか確認
   ```bash
   curl http://localhost:3456/health
   ```
2. サーバーのログを確認
3. ファイアウォールがポート3456をブロックしていないか確認

### 問題2: マイクが動作しない

**原因**: マイクの権限が許可されていない

**解決方法**:
1. Chromeの設定を開く: `chrome://settings/content/microphone`
2. 拡張機能がマイクを使用できるように許可
3. サイドパネルをリロードして再試行

### 問題3: 拡張機能が読み込めない

**原因**: manifest.json にエラーがある、またはファイルが不足している

**解決方法**:
1. 拡張機能の管理画面でエラーメッセージを確認
2. 以下のファイルがすべて存在するか確認：
   - `manifest.json`
   - `sidepanel.html`
   - `sidepanel.css`
   - `sidepanel.js`
   - `background.js`
   - `content.js`
3. ファイルに構文エラーがないか確認

### 問題4: 特定のページで動作しない

**原因**: Chrome拡張機能のポリシー制限

**解決方法**:
- `chrome://` や `about://` などの特殊なページでは、Chromeのセキュリティポリシーにより拡張機能が動作しません
- 通常のWebページ（https:// や http://）で使用してください

### 問題5: DevToolsでデバッグしたい

**サイドパネルのデバッグ**:
1. サイドパネルを右クリック
2. 「検証」を選択
3. DevToolsが開きます

**バックグラウンドスクリプトのデバッグ**:
1. `chrome://extensions/` を開く
2. Jev Voice Browserの「サービスワーカー」をクリック
3. DevToolsが開きます

**コンテンツスクリプトのデバッグ**:
1. 通常のページでF12キーを押してDevToolsを開く
2. コンソールにログが表示されます

## セキュリティに関する注意事項

### APIキーの管理

- **拡張機能のコードには絶対にAPIキーを含めないでください**
- APIキーは常にサーバー側（`third_party/jev-voice-browser/.env`）で管理されます
- 拡張機能は認識リクエストをサーバーに転送するだけです

### 通信の安全性

- 拡張機能とサーバー間の通信はWebSocketを使用します
- 現在はlocalhost（開発環境）でのみ動作します
- 本番環境では、HTTPS/WSSを使用し、適切な認証を実装してください

### 権限について

この拡張機能は以下の権限を要求します：

- `activeTab`: 現在のタブの情報を取得
- `tabs`: タブの管理とスクリーンショット
- `sidePanel`: サイドパネルの表示
- `storage`: 設定の保存
- `scripting`: コンテンツスクリプトの注入
- `<all_urls>`: すべてのWebページでの動作（必要に応じて制限可能）

## アンインストール

拡張機能を削除する場合：

1. `chrome://extensions/` を開く
2. Jev Voice Browserの「**削除**」ボタンをクリック
3. 確認ダイアログで「**削除**」をクリック

サーバーも停止する場合：

```bash
# サーバーが起動しているターミナルで Ctrl+C を押す
```
