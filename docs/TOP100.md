# AI Top100 の更新

`index.html` と `index.slim.html` のボードは、公開ポストの**時点スナップショット**です。表示中の閲覧数・いいねは収集した瞬間の値で、その後の増減は追いません。新しい投稿ほど閲覧数が伸びきっていないため、同じ日数の窓でも古めの投稿が有利になります。

X の For You タブは使いません。ログイン済みブラウザでの取得やスクレイピングもありません。入力は、別の場所で保存した公開の X API v2 レスポンス JSON だけです。For You ボード（`foryou.html` / `foryou-data.json`）の更新手順は [REFRESH.md](REFRESH.md) のままです。

## いま入っているスナップショット

- 収集: 2026-10-20 04:23〜04:28 JST（`2026-10-19T19:28:49Z`）
- 窓: `start_time=2026-10-12T19:30:00Z` から収集時点まで。実投稿は 2026-10-13 08:10 JST 〜 2026-10-20 03:14 JST
- 取得: AI 関連アカウント約 60 件のユーザー投稿（`exclude=replies,retweets`、各最大 25 件、ページングなし）と、英語・日本語のキーワード検索数件。引用は残す
- ラベル: `data-meta.json` の `updated_label` は `2026-10-20 更新`

キーワード検索は関連度順でも閲覧数の少ない投稿が大半で、上位はほぼハンドル指定の取得から来ています。投稿が多いアカウントは 25 件で打ち切られているため、7 日分を取り切れていません。選んでいないアカウントのバズは入りません。

生のレスポンスは容量が大きいのでリポジトリには置きません。この回の日本語訳だけ `top100-ja.json` にあります。

## ワンコマンド

レスポンス JSON（`data` が投稿配列、`includes.users` / `includes.media` 付き）を一つのディレクトリに置いて実行します。ユーザー解決だけのレスポンスや 0 件の `meta` は無視します。ファイルは名前順に読み、投稿本文は先勝ち、プロフィールとメディアは後勝ちです。

```sh
node scripts/build-top100.mjs --raw /path/to/raw/x --translations top100-ja.json --updated 2026-10-20
node --test tests/
```

`--updated` は収集日（JST の `YYYY-MM-DD`）です。`updated_label` は `2026-10-20 更新` になります。`--dry-run` は件数だけ出して保存しません。`--out DIR` で出力先を変えられます。

書き出されるもの:

- `data-meta.json` … タイトル、更新ラベル、`target` 100、`seeded`（実際の件数）、`page_size` 50、`pages`
- `data-part1.json` から 25 件ずつ。100 件なら part4 まで。余った `data-partN.json` は削除します
- 出力先に `index.html` / `index.slim.html` があれば、その `board-data` を同じ内容に差し替えます。ページは part ファイルを取りに行かず、この埋め込みだけを表示します

翻訳ファイルは `{"投稿ID": "日本語"}` です。ID が無い投稿は `lang` が `ja` のとき snippet をそのまま使い、それ以外は `snippet_ja: null`（画面は原文 snippet に戻ります）。このスナップショットの上位 100 件は `top100-ja.json` で埋まっています。通信による自動翻訳はしません。

## ランキング

1. 投稿 ID で重複除去。`referenced_tweets` に `replied_to` または `retweeted` があるものは除外。引用（`quoted`）は残す
2. 公式アカウント（`PASS_OFFICIAL`）は本文を見ずに残す。それ以外は本文が AI 関連の語（大文字小文字を区別する `AI` / `LLM` / `GPT` などと、区別しない `OpenAI` / `Claude` / `モデル` / `エージェント` など）に一致する場合だけ残す。語の途中（`IKIGAI` の `AI` など）は一致させない
3. 空本文、`https://t.co/...` だけの本文、スパムハンドル（API 販売など。`SPAM_HANDLES`）を除外
4. 目視除外（`MANUAL_EXCLUDE`）。この回は政治の投稿 `2112015643126165669` と、AskTaxGPT に当たった株リスト `2112035832857002481`。次回、外したい ID があればここを編集する
5. 閲覧数（`impression_count`）の降順、同数ならいいね数の降順。同点は入力順を維持
6. 1 ハンドル最大 4 件。上位 100 件をボードにする

`metric` は閲覧数（0 ならいいね数）を K/M/B にする。10 未満は小数 1 桁（`9.6M`）、10 以上は整数（`21M`）。`9.965K` のように丸めた結果だけが 10 になる場合は `10.0K` のまま。

本文は末尾の t.co リンクを 1 つ落とす。`snippet` は空白と改行を 1 つの空白に畳み、140 文字（コードポイント）を超えたら先頭 140 文字に `…` を付ける。`text` は畳まない。アバター URL の `_normal.` は `_200x200.` にする。メディアは最初の画像 URL、無ければ動画サムネ、無ければ `null`。

## カテゴリ

上から順に、最初に当たったものを使う。

1. 本文に `jev` → `jev`
2. 公式アカウント（カテゴリ用の集合。`nvidia` を含み、`ArtificialAnlys` は含まない）で、リリース系の語（`now` / `new` / `available` / `launch` / `today` / `公開` / `発表` など）→ `発表`
3. 評価系の語（`benchmark` / `eval` / `safety` / `risk` / `ベンチマーク` / `性能` / `評価` など）→ `評価`
4. 公式アカウント、またはラボ幹部（`sama` / `elonmusk` / `DarioAmodei` / `karpathy` など。`LAB_PEOPLE`）→ `研究所`
5. それ以外 → `その他`

この順なので、幹部の製品発表は `研究所`、公式のリリース告知に評価語が混ざっていても `発表` になる。

## テスト

`tests/fixtures/top100/` は小さい合成レスポンスです。CI の Node.js 20 は `node --test tests/` で、フィクスチャの順位・カテゴリ・snippet と、公開中の part ファイル / 両 HTML の `board-data` が同じ規則に沿っていることを確認します。Node.js 22 ではディレクトリ引数を渡すと失敗するので、同じ内容を `node --test tests/*.test.mjs` で実行します。
