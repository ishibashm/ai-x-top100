### データ更新

最短手順：`foryou-data.json` の対象アカウントの `posts`・`sample`・`updatedAt` を更新 → `node scripts/build-foryou.mjs` → JSONとHTMLを一緒に反映。

### 使いやすさの改善

- アカウント選択を44px以上の高さとアクセント色で強調。ページ移動ボタンも44px四方以上にし、タップしやすくしました。
- 最終更新を「○時間前」の相対時刻で表示し、ツールチップに端末の現地時刻、未取得は「未取得」と明記。実表示範囲（例：51–52 / 52件）も表示します。
- すべてのカードはタップで拡大表示し、URLがある投稿は「Xで開く」から別タブへ移動できます。長文は本文内のページ切替で読めるためスクロール不要です。拡大表示の言語切替はボードの設定を変えません。閉じるボタンまたはEscで戻れます。
- 空状態から他のアカウントに直接切り替えられます。データ破損時には再読み込みボタンと更新手順リンクを表示します。
- Top100の `index.html` と `index.slim.html` には往復用リンクのみ追加し、既存の投稿データと表示処理は維持しています。

### データ形式

`foryou-data.json` の `accounts` 内で対象の `handle` を探し、その `posts` をおすすめの表示順に更新します。アカウントの `handle` と投稿作者の `handle` は別物です。自分の投稿だけに絞り込む処理はありません。

```json
{
  "name": "Emerald Glen",
  "handle": "GazerStar79330",
  "sample": false,
  "updatedAt": "2026-09-19T12:00:00Z",
  "posts": [
    {
      "id": "実際の投稿ID（文字列）",
      "author": "投稿作者名",
      "handle": "投稿作者のハンドル（@なし）",
      "text": "原文",
      "textJa": "任意の日本語訳",
      "avatar": "https://example.com/avatar.jpg",
      "media": "https://example.com/thumbnail.jpg",
      "metrics": { "views": 1200, "likes": 35 },
      "url": "https://x.com/投稿作者/status/実際の投稿ID",
      "createdAt": "2026-09-19T11:00:00Z"
    }
  ]
}
```

`id`・`author`・`handle`・`text` は必須です。`name` を `author` の代わりに使用でき、既存形式の `snippet`・`snippet_ja`・`views`・`likes` も表示できます。翻訳・画像・メトリクス・URL・日時は省略可能。`lang` に原文の言語（`ja` / `zh` / `en` など）を指定できます。漢字だけの文は日本語の可能性もあるため中国語と断定せず「言語不明」と表示します。メトリクスはviewsを優先し、なければlikesを表示します。実データへの差替え時に `sample: false` と取得日時を設定してください。

更新後、Node.jsで以下を実行し、JSONと生成されたHTMLを一緒に保存・コミットします。

```sh
node scripts/build-foryou.mjs
node scripts/build-foryou.mjs --check
```

生成処理はデータを検証し、`<` などをUnicodeエスケープしてscript要素への安全な埋め込みを行います。ブラウザ側でも本文をHTMLとして解釈しません。実取得・自動ログイン・スクレイピングは実装していません。


### アカウント追加

`foryou-data.json` の `accounts` 配列に同じ形式のオブジェクトを足せば、切替にアカウントを追加できます（件数の上限はありません）。追加後は `node scripts/build-foryou.mjs` を実行してHTMLを再生成してください。

### 件数連動レイアウトを選んだ理由

現在のページにある投稿数に合わせ、1〜3件は同数の列、4〜9件は3列、10〜24件は4列、25〜50件は5列にし、行数を必要数だけ確保します。固定50枠を埋める方式をやめることで、20件・24件のアカウントでもiPadの画面を有効に使えます。少数時は文字とサムネイルを大きくし、画像なしの投稿には本文全幅を割り当てます。高さは画面内に収め、長文は拡大画面の本文ページ切替で読むため、ボードのスクロールは不要です。最後のページも同じ規則で拡大します。

### 翻訳の運用と追加UX

日本語トグルは保存済みの `textJa` を優先し、原文トグルは常に元の `text` を表示します。既存23件の翻訳は追加費用やネット接続なしで表示できます。取得元で途切れている投稿の続きを補完せず、取得範囲を翻訳しています。データ更新時は中国語・英語などの本文訳を `textJa` に追加し、本文が変わったら翻訳も更新してビルドしてください。未登録の場合は拡大画面に原文と翻訳ボタンを出します。このフォールバックは外部ページでの翻訳であり、ボードへ訳を自動保存するものではありません。課金APIキー・非公式翻訳プロキシは不要です。ブラウザ内蔵翻訳APIは[デスクトップChrome向け](https://developer.chrome.com/docs/ai/get-started)でiPadでは利用できないため、保存済み翻訳を優先しました。

- 全カードから本文を拡大して読める操作に統一し、原文／訳文・Xへのリンクを集約。
- 少数件数の案内、正確な最終ページ範囲、更新の相対時刻。
