# AI X Top 100 / AI情報 Top 100

iPad向けのスクロールなしボード。AI関連の注目ポスト Top 100 をリッチカードで表示します。

- 1画面50件
- ヘッダーで「1–50」「51–100」切替（左右スワイプ可）
- 「日本語／原文」トグル（localStorageに保存）
