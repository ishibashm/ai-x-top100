# AI X Top 50 / AI情報 Top 50

iPad向けのスクロールなしボード。AI関連の注目ポスト Top 50 をリッチカードで表示します。

カードには作者、スニペット、サムネイルなどが表示されます。

ヘッダーの言語トグル（「日本語」／「原文」）でスニペット表示言語を切り替えられます。デフォルトは日本語、localStorageで設定を記憶します。
